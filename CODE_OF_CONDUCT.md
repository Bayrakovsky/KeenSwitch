# Code of Conduct

KeenSwitch adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text is maintained upstream — please read it there.

The short version: everyone interacting in this project's repositories, issue
trackers, pull requests, discussions, and any related channels is expected to
foster an open, welcoming, and harassment-free environment. Be respectful of
differing viewpoints. Assume good faith. Disagree with ideas, not with people.

## Scope

This Code of Conduct applies within all project spaces — issues, pull requests,
discussions, commit messages, and any communication that happens because of this
project — and also when someone is officially representing the project in public.

## Reporting

If you experience or witness behavior that violates the Code of Conduct, please
report it privately:

- **Email**: stanislav.job@gmail.com (subject line `[KeenSwitch CoC]`)

Reports will be reviewed and handled confidentially. The maintainer will respond
within a reasonable timeframe and may take any action they deem appropriate, up
to and including banning the offender from project spaces.

If the report involves the maintainer, please escalate through GitHub's
[abuse reporting flow](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
instead.
